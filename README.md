# Infra Monitoring Project
A DevOps project for API availability monitoring,
log analysis, network traffic inspection, and containerized deployment.

## Project components

- Bash scripts for API checks and log analysis
- Wireshark traffic capture and analysis
- Docker Compose with an API service and Nginx reverse proxy
- GitHub Actions CI/CD workflow
- SSH/SCP deployment instructions

## Development workflow

Development is performed in the 'feature/monitirong' brach.
Changes are proposed for integration info 'main' through a Pull Request.
